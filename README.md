# Psicoanálisis Freud — Segundo parcial

Proyecto hermano de `psicoanalisis-freud-laznik`, destinado al libro de estudio del segundo parcial de Psicoanálisis Freud, cátedra Laznik (UBA).

## Alcance

- Módulo 3: Pulsión, fantasía y narcisismo.
- Módulo 4: Represión, inconsciente, transferencia, ganancia de la enfermedad y angustia.

## Fuentes de trabajo

- Bibliografía y guías: `psicoanalisis-freud-laznik-lectura-2do-parcial`.
- Libro del primer parcial: referencia editorial y estructural.
- `material-raw/notas-de-clase/`: transcripciones de teóricos, prácticos y seminarios.

Las notas de clase se conservan como material primario. El contenido editorial derivado se desarrollará en `libro/bookops/` sin reemplazar ni corregir silenciosamente las transcripciones originales.
