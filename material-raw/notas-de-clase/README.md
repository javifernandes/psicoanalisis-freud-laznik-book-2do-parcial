# Notas de clase

Transcripciones personales de los tres espacios de la materia.

Se pueden completar progresivamente. Para cada clase alcanza con indicar, cuando sea posible:

- número o fecha de la clase;
- textos trabajados;
- transcripción libre;
- dudas o pasajes inciertos marcados con `[duda]`;
- palabras ilegibles o faltantes marcadas con `[¿...?]`.

No hace falta limpiar el estilo ni desarrollar las abreviaturas antes del análisis editorial.
