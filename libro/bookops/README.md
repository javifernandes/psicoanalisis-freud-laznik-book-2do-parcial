# Psicoanálisis Freud — Segundo parcial

Material de estudio para el segundo parcial de Psicoanálisis Freud, cátedra Laznik. El libro reconstruye la lectura de la materia a partir de las guías, los textos de Freud y las notas de teóricos, prácticos y seminarios.

## Tesis del recorrido

La introducción de la pulsión transforma la etiología, el cuerpo, el aparato psíquico, el yo, el síntoma y la técnica. El segundo parcial estudia las consecuencias de esa transformación.
